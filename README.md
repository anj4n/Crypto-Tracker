
🚀 Crypto Tracker (React)

A cryptocurrency tracking web app built with React JS that displays real-time market data using the CoinGecko API.

🔗 Live Demo: https://crypto-tracker-j32i-g3mdmtj11-anjan-thapas-projects.vercel.app/

✨ Features

Real-time cryptocurrency prices

Market cap & 24h trading volume

Search and filter functionality

Detailed individual coin pages

Historical price data

Client-side routing using React Router

🛠 Tech Stack

React JS

React Router

CoinGecko API

React Hooks

⚙️ Setup (Local)
git clone https://github.com/anj4n/crypto-tracker.git
cd crypto-tracker
npm install
npm start


Runs on http://localhost:3000
